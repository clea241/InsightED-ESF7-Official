# Prompt Refinement Rules

When refining a user prompt:
1. **Analyze Intent**: Identify what component, endpoint, or feature the user is asking to build or fix.
2. **Detect Ambiguities**: Identify missing details (e.g. state management, API routes, data structures, styling requirements, error handling).
3. **Draft Clarifying Questions**: Ask concise, high-value questions for missing critical choices.
4. **Construct Refined Prompt**: Produce a clear, actionable, structured specification for AI coding assistants (like Antigravity).
5. **Extract Knowledge**: Identify any new domain rules or user preferences stated in the conversation that should be added to `.agents/memory/`.
